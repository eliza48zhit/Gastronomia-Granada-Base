Este despliegue aplica estandares de desarrollo robustos en Solidity:

Hito de la Serie: Vigesimoseptimo bloque completado. Se utiliza la variable especiaReina para documentar el perfil aromatico predominante (ej. Nuez Moscada, Canela, Clavo), un factor determinante en la alquimia culinaria granadina.

Integridad del Codigo: Arquitectura lineal diseñada para evitar errores de desbordamiento y optimizar el uso de gas en la red Base.

Cero Caracteres Especiales: Codigo limpio de caracteres Unicode para garantizar una lectura tecnica impecable y evitar el ParserError detectado en despliegues previos.

Licencia Abierta: Implementado bajo SPDX-MIT.

📖 Modo de Uso

Consultar el Oil Down: En la pestaña Read Contract, usa consultarPlato (ID 1) para verificar la Nuez Moscada como especia protagonista del registro inicial.

Registrar Tradicion: En la pestaña Write Contract, usa registrarPlato para añadir platos como "Nutmeg Ice Cream" (Especia: Nuez Moscada) o "Sweet Potato Pudding" (Especia: Canela).

Votacion Inmutable: Sistema de Likes y Dislikes para medir la popularidad de la gastronomia de Granada en la blockchain.
